About the model

ANC-Net v3 — signal path

  1. Two microphones: boom (talker + battlefield) and ear-cup reference (battlefield, talker 12–18 dB down).
  2. Asymmetric STFT 256-sample analysis / 128-sample synthesis, hop 64 → 129 bins, 250 frames/s. Algorithmic latency 8 ms + 4 ms, fully causal.
  3. Input maps: complex spectra of both mics + inter-mic log-magnitude ratio + log|boom|.
  4. Complex conv encoder (4 stages, 16/32/48/64 ch, stride 2 in frequency, one-frame look-back) → 1×1 bottleneck.
  5. Onset stream: 12 scalars per hop (log-energy, flux, crest of four 1 ms sub-hops) for 1 ms gunshot crack resolution.
  6. 2 × GRU(128) with explicit state — streams hop by hop.
  7. Heads: gunfire / blast / none per frame (the detector strip above) and a gain g(t) ∈ [0.1, 1] — learned transient suppressor.
  8. Complex decoder with skips → tanh-bounded complex ratio mask on the boom spectrum, 3-tap smoothed → iSTFT → × g(t).
